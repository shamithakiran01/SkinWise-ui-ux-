SkinWise is a user-centric mobile app designed to provide personalized skincare recommendations based on user input, skin type, and concerns. The UI focuses on a clean, calming aesthetic with intuitive navigation to ensure a seamless experience. As the designer, I conducted user research to identify pain points in existing skincare apps, created user personas, sketched wireframes, and built high-fidelity interactive prototypes in Figma. The design emphasizes accessibility, easy onboarding, and trust through visual clarity and user-friendly language.

Key Features Designed:

Skin analysis questionnaire flow

Personalized product recommendation screens

Minimalist daily skincare routine tracker

Dark/light mode compatibility

Clean visual hierarchy using soft tones and consistent iconography
